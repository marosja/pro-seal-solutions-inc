# SEO Content Requirements

## File Purpose

This file defines the SEO content requirements for the Pro Seal Solutions Inc. one-page website.

The purpose of SEO content is to help the website rank for local Calgary-area searches related to epoxy flooring, concrete floor coatings, concrete repair, resurfacing, self-leveling, and concrete surface preparation.

SEO content should support the main business goal: generating qualified quote requests through phone calls, contact form submissions, and WhatsApp inquiries.

## SEO Positioning

Pro Seal Solutions Inc. should be positioned primarily as an epoxy flooring and concrete surface solutions company serving Calgary, Alberta and surrounding areas.

The website should not present the company as a general concrete pouring or new concrete installation contractor. The focus should remain on services performed after concrete is already installed, including surface preparation, repair, resurfacing, leveling, coatings, and epoxy flooring.

## Primary SEO Focus

The primary SEO focus of the website is:

**Epoxy flooring and concrete floor coatings in Calgary, Alberta.**

This should be the strongest keyword direction across the page title, hero section, service descriptions, image alt text, and contact section.

The secondary SEO focus is:

**Concrete surface repair, resurfacing, self-leveling, and preparation for residential and commercial properties.**

## Project Gallery SEO Requirements

The project gallery should support SEO without slowing down the page.

### Image File Naming

Use descriptive, lowercase file names with hyphens.

Good examples:

```text
epoxy-garage-floor-calgary-after-01.webp
concrete-flake-coating-calgary-after-01.webp
driveway-restoration-calgary-before-01.webp
driveway-restoration-calgary-after-01.webp

```

Avoid file names like:

```text
IMG_4920.jpg
photo1.png
final-edit-new.jpg
floorpic.jpeg
```

### Image Alt Text Rules

Alt text should describe the actual image. Do not stuff keywords unnaturally.

Good alt text should include:

- Surface type

- Location if relevant
- Before or after status if applicable

## Technical SEO Requirements

The website should support SEO through performance, accessibility, and clean structure.

### Performance

Requirements:

- Compress all gallery images.
- Use modern image formats such as WebP where possible.
- Lazy-load gallery images below the fold.
- Avoid large JavaScript libraries unless necessary.
- Avoid heavy animations and video backgrounds.
- Minify CSS and JavaScript.
- Use responsive image sizes.
- Keep the one-page website lightweight.

### Mobile SEO

Requirements:

- Fully responsive layout.
- Tap-friendly phone, quote, and WhatsApp buttons.
- Readable font sizes on mobile.
- No horizontal scrolling.
- Fast loading on mobile connections.
- Quote form must be easy to complete on a phone.

### Accessibility SEO

Requirements:

- One clear H1.
- Logical heading order.
- Descriptive link text.
- Descriptive form labels.
- Alt text for meaningful project images.
- Strong text contrast.
- Keyboard-accessible form fields.
- Visible focus states.

## Content Quality Rules

SEO content must sound natural and professional. Avoid keyword stuffing.

### Good SEO Writing

Good example:

```text
We install durable epoxy flooring and concrete floor coatings for garages, shops, warehouses, and commercial spaces in Calgary.
```

### Bad SEO Writing

Bad example:

```text
We are the best epoxy flooring Calgary epoxy floor coating Calgary concrete coating Calgary garage epoxy Calgary company.
```

### Tone

SEO text should be:

- Clear
- Professional
- Trustworthy
- Local
- Service-focused
- Easy to scan
- Written for real customers first, search engines second
