# Image Usage Notes

## Website gallery usage

Use the best images from each project on the homepage gallery.

Recommended MVP image count:
- Commercial epoxy flooring: 4–6 images
- Residential garage flake coating: 4–6 images
- Driveway and stairs restoration: 4–6 images

Avoid loading every full-size original image directly on the homepage.

## Optimization requirements

Before publishing:
- Compress images.
- Create WebP or AVIF versions where possible.
- Keep JPG fallback versions if needed.
- Use responsive image sizes.
- Lazy-load gallery images below the fold.
- Use descriptive `alt` text.
- Do not use generic alt text such as “image”, “photo”, or “project picture”.

Suggested optimized image sizes:
- Thumbnail: 400–600 px wide
- Gallery preview: 900–1200 px wide
- Large/lightbox image: 1400–1800 px wide if needed

## Filename handling

Current filenames are acceptable as source filenames.

For optimized production images, recommended naming style is lowercase kebab-case.

Example:
`full-1.jpg`

Could become:
`commercial-epoxy-warehouse-full-view-1.webp`

## Important wording rules

Use:
- epoxy flooring
- floor coatings
- concrete coatings
- concrete repair
- concrete restoration
- concrete resurfacing
- concrete surface preparation
- garage floor coating
- commercial epoxy flooring
- residential flake coating

Avoid:
- concrete pouring
- new concrete installation
- concrete laying
- poured concrete contractor
- foundation pouring
- slab installation

The company should be described as working on existing concrete surfaces, coatings, restoration, and preparation.
